# Smart Expense Analyzer - Simple Python Version

## Project
A simple Python college project for recording expenses, setting a budget, and viewing spending totals.

## Technologies
- Python
- Tkinter
- SQLite

## Main Modules
1. User registration and login
2. Add/view/delete expenses
3. Budget and spending summary

## How to Run
1. Install Python 3.
2. Open the project folder.
3. Run:

```bash
python main.py
```

The SQLite database `expenses.db` is created automatically.

## Why this version is simple
The project uses functions, SQLite, and Tkinter instead of a large multi-class architecture. This makes the code easier to understand and explain in a viva.

## Functional Requirements
- User can register.
- User can log in.
- User can add an expense.
- User can view expenses.
- User can delete an expense.
- User can set a budget.
- User can view total spending and remaining budget.

## Non-Functional Requirements
- Simple user interface
- Input validation
- Local database storage
- Fast response for normal use
- Easy to maintain and understand
