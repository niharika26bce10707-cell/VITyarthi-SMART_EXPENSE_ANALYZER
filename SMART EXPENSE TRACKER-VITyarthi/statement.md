# Project Statement

## Title
Smart Expense Analyzer

## Problem
Students and small users may find it difficult to keep track of daily expenses and compare spending with a budget.

## Proposed Solution
The Smart Expense Analyzer is a Python desktop application that stores expenses in SQLite and provides a simple Tkinter interface. Users can register, log in, add expenses, delete expenses, set a budget, and view a spending summary.

## Project Objectives
- Practice Python programming.
- Use Tkinter for GUI development.
- Use SQLite for database storage.
- Apply input validation.
- Build a complete small application suitable for academic submission.

## Scope
The project focuses on basic personal expense management. Advanced online banking, payment processing, and cloud synchronization are outside the scope.
